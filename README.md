Overview

This repository contains the complete code required to reproduce all figures presented in “Temperature-Precipitation Regimes Shape Divergent Responses of Autumn Phenology across the Northern Hemisphere”, including main figures, extended data figures, and supplementary information figures. It also contains code for autumn phenology modeling, projection, and causal effect calculation.
